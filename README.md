# Beecrowd 1047 - Tempo de Jogo com Minutos



## Descrição



Este programa resolve o problema 1047 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém quatro valores inteiros que representam a hora e o minuto de início e a hora e o minuto de término do jogo.



## Saída



O programa apresenta a duração do jogo no formato:



**O JOGO DUROU X HORA(S) E Y MINUTO(S)**
